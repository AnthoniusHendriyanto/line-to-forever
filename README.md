# Line to Forever

Wedding Invitation for Anthon & Melisa.

## Wedding details

Date, venue, and map link live in `src/components/wedding/weddingConfig.ts`. Update them there once.

## RSVP and gifts

Both sections are UI-only for now. Submitting shows a "coming soon" notice and does not
send anything. Wire them to a backend when the RSVP/gift service is ready.

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run test` – unit tests
- `npm run lint` – lint
